# Disaster-Recovery Readiness and Certification

> **Status:** Canonical index
> **Audience:** Engineering leaders, operators, auditors
> **Purpose:** Route readers to formal evidence without duplicating it
> **Owner:** Operations and Engineering Leadership
> **Related documents:** [Certification portal](../../certification/README.md), [validation and certification](../../architecture/12_VALIDATION_AND_CERTIFICATION.md)

- [MR-014 Multi-Site Certification](../../certification/MR-014_MULTI_SITE_CERTIFICATION.md) proves the bounded routing and worker failure envelope.
- [MS-024A Pre-Production Readiness Certification](../../certification/MS-024A_PRE_PRODUCTION_READINESS_CERTIFICATION.md) applies the pre-production policy and records accepted warnings.
- [Readiness profiles](../../architecture/platform-resilience/MS-024A_PRODUCTION_READINESS_PROFILES.md) define which controls each environment requires.
- [Production readiness certification](../../architecture/platform-resilience/MS-024_PRODUCTION_READINESS_CERTIFICATION.md) defines the stricter production gate.

Architectural acceptance, runtime failure certification, and production certification are distinct states.
