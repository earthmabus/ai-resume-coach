# Certification Records

> **Status:** Canonical index
> **Audience:** Engineering leaders, auditors, operators
> **Purpose:** Preserve and explain formal certification evidence
> **Owner:** Engineering Leadership and Operations
> **Related documents:** [Validation and certification](../architecture/12_VALIDATION_AND_CERTIFICATION.md), [DR certification guide](../mvp2-disaster-recovery/certification/README.md)

Formal records:

- [MR-014 Multi-Site Certification](MR-014_MULTI_SITE_CERTIFICATION.md): bounded routing isolation, survivor work, worker interruption, recovery, and reconciliation.
- [MS-024A Pre-Production Readiness Certification](MS-024A_PRE_PRODUCTION_READINESS_CERTIFICATION.md): profile-aware readiness with explicit non-production exceptions.

Certification proves the named contract against the recorded deployment and conditions. It does not automatically carry forward after material architecture changes, replace continuous monitoring, or imply production-profile approval.
